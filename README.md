## 📖 About the Project

**GreenNest** is a decoupled web application designed to connect nature enthusiasts with top-quality plants, seeds, pots, and professional gardening services. It provides a seamless e-commerce experience for plant shopping alongside a dedicated platform for booking expert gardeners. 

The application is structured into multiple portals to serve customers, vendors, and platform administrators efficiently, providing an all-in-one ecosystem for the botanical community.

## ✨ Core Features & Portals

*   **🌱 Customer Portal:** A user-friendly interface for browsing plant collections (featuring items like Monstera Deliciosa, French Lavender Seeds, and Spathiphyllum), purchasing gardening accessories, and booking professional gardeners.
*   **🪴 Vendor Portal:** A dedicated workspace for sellers and nurseries to manage their product listings, track inventory, and handle customer orders[cite: 2].
*   **⚙️ Admin Portal:** A centralized dashboard for platform oversight, user management, and performance monitoring[cite: 2].
*   **🔐 Auth & User Profiles:** Secure authentication flows and customizable user profiles for a personalized shopping experience[cite: 2].

## 🛠️ Tech Stack

Built for speed and maintainability using a modern frontend stack:
*   **Framework:** React with TypeScript (`.tsx`)[cite: 2].
*   **Build Tool:** Vite for blazing-fast hot module replacement and optimized production builds[cite: 2].
*   **Styling:** Tailwind CSS for a highly responsive, custom design system[cite: 2].
*   **Deployment:** Vercel

### Prerequisites
